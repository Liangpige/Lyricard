# v0.3.3 — 封面不再骗人，播放器名单不再玩失踪

一句话：这一版几乎全在修「看起来坏了但说不清哪里坏」的东西——**占位封面被当真封面**、**一次解码失败就永久空盘**、**开始菜单扫描一直是 0**、**名单会自己变形**。

## 一、封面：三层问题，逐个拆

### 1. 一次失败，空到重启

`Tick` 里原来是先记账后干活：

```csharp
_lastArt = rawArt;      // 先记「这张已经应用过了」
ApplyArt(rawArt);       // 干活，整体包在 try/catch 里
```

`ApplyArt` 里解码、调色（`FadeArt`）、建 `ImageBrush` 任一步抛异常，异常被 catch 吃掉只写日志，可 `_lastArt` **已经等于那张图**了。之后每帧 `ReferenceEquals` 都判「已应用」，画面上就永远没有封面——重启等于清空 `_lastArt`，所以重启能好。

现在 `ApplyArt` 返回 `bool`，失败时把 `_lastArt` 置空下帧重试；另加 `_artBrush` 缓存与 2 秒节流的「补挂」：`Fill` 掉了就从缓存贴回去（`art restore from cache`）。

### 2. 播放器不给图，我们就把上一张也清空了

歌手换歌但缩略图还没到，旧实现立刻清盘。现在**保留上一张**直到新图到达，同时触发一次联网补图。

### 3. 酷狗发来的「没有封面」占位图，被当成了封面

酷狗没有封面时不是不给图，而是发一张占位盘。它有四种长相，前三种颜色各异，第四种是纯白光滑盘：

| 长相 | 旧规则 | 新规则 |
| --- | --- | --- |
| 中性灰「K」标 | 抓得到 | `grey` |
| 粉/紫模糊 CD | **抓不到**，当真封面 | `tinted` |
| 带旋转纹理的盘 | **抓不到** | `rot`（与 90° 旋转图的差） |
| 纯白光滑盘 | **抓不到** | `edge`（邻域梯度） |

判据（任一命中即视为占位图，随后联网补真图）：

```
neutralTile = share>=0.70 && std<=34 && mean>=150
flatTintTile= lowChroma>=0.60 && std<=22 && mean>=150
discTile    = rot<=8.0   && std<=26 && mean>=120
smoothTile  = edge<=4.5  && std<=30 && mean>=110
```

真封面的实测值分别是 `rot=70.7 edge=14.4 std=63.9`，稳稳落在门槛外。补图走 QQ 音乐专辑封面（标题完全相等得 1.0、互相包含得 0.85），20 秒内失败可重试。

## 二、歌词匹配：别再把片段当整首

- 单时间戳、少于 60 秒、名字里带「片段 / 试听 / 伴奏 / DJ版 / 女声版 / 演唱会」的一律降权或直接丢弃；
- 命中门槛改成与成熟工具一致的加权：标题 0.50 + 艺人 0.30 + 时长 0.20，时长差 >12 秒直接 0 分；
- 缓存命中也要过一遍今天的判据（`#score=` 头），旧缓存里那批「当年看着能过」的条目会被重搜（`cache stale`）；
- 酷狗只查它读得懂的标题（英文/数字），中文标题交给 QQ / 网易云。

## 三、播放器名单：从「检测到什么就显示什么」改成「永远列全」

以前列表由检测结果驱动，于是：

- 开始菜单扫描从几个月前起一直是 `shortcuts=+0`。真正的根因不是注释里写的 COM 晚绑定，而是
  `Directory.GetFiles(..., AllDirectories)` 碰到**一个拒绝访问的子目录**就整体抛 `UnauthorizedAccessException`，被 `catch { return; }` 吞掉——88 个快捷方式一个都没读；
- 结果就是 MD3Music 这类「只有快捷方式」的播放器被判定为未安装，直接从名单里消失。

现在：

- `.lnk` **直接按二进制格式解析**（LinkInfo 的 `LocalBasePath + CommonPathSuffix`，再读五个 StringData，最后兜底扫字节里的 `*.exe`），不再经过 COM；
- 目录**逐层走**，每层单独 try/catch，跳过 reparse point。实测 `lnk 55 -> 46` / `lnk 33 -> 32`，`shortcuts` 从 **0 → 57**；
- 名单**常显全部内置播放器**，没检测到的标「未检测到」、开关置灰且不挂鼠标事件（点不动，也不会被误绑）；
- 新增 **Salt Player for Windows**（商店版靠 AUMID 里的 `sakawish`，Steam 版靠 `saltplayer.exe`）；
- 移除 **AIMP**（一条 SMTC 会话都不发）与 **foobar2000**（要插件，便携版也没有快捷方式可查）。配置里指向它们的旧绑定会在加载时清掉并重写一次，日志记 `dropped retired player binding`。

现在内置 9 家：Apple Music、Spotify、网易云音乐、QQ 音乐、酷狗音乐、MD3Music、Salt Player、MusicBee、Windows 媒体播放器。

## 四、外观两处小修

- 艺人颜色以前只作用于「同框」时行内那一段，不同框时的独立 `TextBlock` 拿不到，必须重启才变——现在两处一起刷；
- 「歌名艺人同框」时艺人按行盒**底部**对齐（`BaselineAlignment.TextBottom`），不再浮在标题基线上。不同字体下仍会差 1 px，来自字形下伸，属字体行为。

## 五、时长缺失时的兜底

客户端不报总长（`dur=0`）时，用「歌词最后一句 + 5 秒」估一个；这样进度条不会一直空着，单曲循环也不会走出歌尾。
