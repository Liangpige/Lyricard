## 这次主要是「手感」

功能没加几个，重点是把交互的细节补齐——这一版之后，点按钮、切页签、拨开关应该都有回应，而不是只看结果。

### 交互动效

- **页签下划线会生长**：选中时从文字中心向两侧铺开到满宽（200 ms，ease-out），切走时 90 ms 收回 55% 再淡出。
- **页签文字会亮**：悬停时从灰提亮到接近纯白（120 ms 进、170 ms 出）。只给底色的话像 tooltip，字亮起来才像"活的"。
- **按下去有回弹**：所有可点元素按下时降到 86% 不透明度并压到 97%（90 ms 按下 / 160 ms 回弹）。原来那 3% 的缩放在 28 px 的胶囊上肉眼根本看不出来。
- **最小化 / 关闭按钮**终于和别处一致（此前是瞬间换底色，现在有淡入淡出 + 按压反馈）。
- **开关**：滑块按住时缩到 94%，行程 160 → 180 ms，轨道与滑块交叉淡变。

### 修掉的问题

- **开关滑块按住时向左漂 1 px**。缩放被叠在位移之后，把 20 px 行程也乘了 0.94；顺序反过来即可。
- **点 × 关闭后，唤回窗口时那颗按钮停在半透明**。`Hide()` 吞掉了鼠标抬起事件，现在抬起时先复位不透明度再执行动作。
- **原地重绘会重播页面动效**。「恢复默认 / 套用预设 / 清缓存 / 切开关」过去都会重播 140 ms 淡入 + 180 ms 上浮，像页面抽了一下；现在同页刷新只换内容、不动画，并保留滚动位置。
- **换曲时封面残留上一首**。播放器先发标题、封面晚一拍，那几拍还挂着旧图；现在换曲当场清空封面再淡入新图。

### 首次使用的默认值

- **歌词时间轴偏移默认 0**（原来是 1.6 秒）。那是我开发时对着 Apple Music 的上报滞后听出来的值，不该让新用户继承；「恢复默认」也一并归零。微调范围钳制在 ±10 秒。
- 已经用过一段时间的配置**不受影响**，`data\config.ini` 里存的偏移原样保留。

### 工程

- `build.sh` 不再屏蔽「未使用的局部变量 / 字段」这类警告，只留 1701/1702/1591/0618 四类无法避免的噪音；每次编译结束打印 `csc exit=0 warnings=N`，有警告时额外提示一行。
- 所有源文件补了文件级注释，说明各自职责。
- README 的播放器数量从「10 家」改正为 9 家；窗口标题与任务栏提示去掉了退役的旧名「浮声」。

### 升级方式

- 已经装过旧版：把新的 `Lyricard.exe` 覆盖过去即可，`data\` 里的配置、歌词缓存、预设全部保留。
- 也可以直接在「关于」页点「检查更新」，让它自己下载、校验 sha256、替换并重启。
- 全新安装：解压 zip 到一个**你自己有写权限**的目录（别放 `C:\Program Files`），双击 `Lyricard.exe`。

### 已知限制（没变）

- AIMP 完全不发 SMTC 会话，只能给一条提示条；Spotify 停在登录页时没有任何会话。
- 浏览器里放的音乐不算播放器，不会出现在卡片上。
- 播放器不报总时长时（foobar2000、本地文件），进度条保持外观但不走进度——不猜，就不会有假进度。
