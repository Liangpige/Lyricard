# Lyricard v0.4.0 — 外观页拆成十个停靠点

这一版把「外观」从头重排了一次，顺手修了几个「看着像玄学」的老问题，并把新用户的默认值改成主人自己那张卡的样子。

## 外观页：左侧十项，各自成页

- 左栏：**画板 / 卡片 / 歌名 / 艺人 / 歌词 / 进度条 / 按钮 / 频谱 / 封面 / 预设**，点谁换谁，标题写成「外观 · 画板」。
- 以前所有设置挤在一张长页里，滚到哪算哪；现在每一项只装自己那点东西，页面不再需要长滚动。
- 左栏逐条淡入（20 ms 递进）、悬停变色、选中右移 2 px；切页有 260 ms 淡入。

**「看着有动效，其实没动」的根因**：`UiMotion.Enter` 用的 `DoubleAnimation(1.0, ms)` 没有起始值，WPF 播完的动画会 hold 在终值，第二次调用起点就取到 1.0，于是 `1.0 → 1.0` 什么都不发生 —— 只有进程启动后的第一次进场是真的。现在先清掉旧时钟、钉住基值，再显式从 0 走到 1。所有可重复播放的动画都按这个规矩写。

## 画板

- 未点「应用」的拖动现在是**草稿**：切去别的页、切去别的 tab 再回来，位置还在；只有「应用」「取消」会清掉。
- 新增 **按钮大小**（18–60）：按钮排按比例缩放并保持水平居中，画板里的「暂停/播放」框同步变大。
- **封面样式（圆形 / 方形）** 从【封面】搬到【画板】，画板里的封面框当场跟着变形状。
- 六个尺寸步进器（歌名/艺人/歌词上限、封面大小、进度条长度、按钮大小）都不再冲掉未应用的拖动。

## 颜色不再串门

- 以前：按钮颜色留空会**借歌词颜色**，律动条颜色留空会**借进度条颜色** —— 所以改歌词颜色，按钮跟着变。
- 现在一个 key 一个颜色，空就是白色。升级时会把旧配置里「正在借」的颜色**冻结**成实色（`ControlsColor` 抄 `LyricColor`、`BarsColor` 抄 `BarFillColor`），所以老用户看到的画面不会突然变白。
- 【卡片】页的「整体透明度」文案改成「整体不透明度」。

## 新用户默认就是这张卡

第一次启动（没有 `config.ini` / `layout.ini`）拿到的就是：缩放 0.73、滚轮无操作、自动清理缓存开、封面色 0.2 / 高光压制 0.08、歌词字号 1.05、按钮色 `#FFC9CCD2`、频谱 300×18、模板 96 的封面 356,40 / 上限 34/16/42 / 按钮 102×30，以及三套内置预设（老版本布局 / 默认2 / 默认3）。

- 【预设】页多了 **恢复默认**：只把外观数值恢复成默认，不动卡片布局，也不删预设。
- 老用户不受影响：这些默认值只在配置文件**不存在**时才写入。
- 设置页那颗「封面阴影（柔光）」删掉了 —— 它控制的光晕早就移除了，拨了没有任何变化。

## 本地歌词

- `data\lrc\*.lrc` 现在**优先且权威**：命中就直接用，越过网络缓存和「6 小时内不再找」的负缓存。
- 解码顺序 BOM → UTF-8（严格）→ GBK，中文歌词不再乱码。
- 只覆盖半首、尾巴很长的歌词也照用（片段过滤只作用于网络结果）。
- 歌词页写明本地文件放哪、必须带时间轴；纯文本歌词不接受。

## 其它

- 主页 / 歌词 / 设置 / 关于四页的左侧留白与右侧对齐（各 31 px），左栏只属于外观页。
- 修掉几处 `MemoryStream` 没释放的封面解码路径。
- 删掉只给开发看的 UI 组件陈列窗（约 700 行）和两个隐藏调试入口，exe 小了一圈。
- 清理 22 条已经没人引用的界面文案。
