## 这次是「模板」

从 0.2.x 的固定版式，改成**你自己画一张卡片**：上面那块画板就是卡片的等比例预览，拖、加、删都在那儿做，点「应用」之后桌面上的卡片才跟着变。

### 画板与模板

- **画板就是卡片**：占位框和桌面卡片用同一套坐标和缩放，1:1，不再出现"画板里这样、桌面上那样"。
- **拖动改位置**：鼠标按住任何一个框拖动即可；尺寸不由拖拽改，而在下面那组选项里改（歌名 / 艺人 / 歌词长度上限，封面大小，进度条长度）。
- **右键增删模块**：显示/隐藏、删除、添加模块。
- **字符上限即框宽**：给某块设「最多 15 个字」，框就按 15 个字收窄，超出部分以 `…` 截断。
- **对齐**：歌名、艺人、歌词各自可选 左 / 中 / 右，在框内对齐。
- **歌名艺人同框**：打开后两段并排一行；关闭则艺人独占一行。
- **刷新**：把画板重新按卡片当前的模板刷新，丢掉没应用的拖动。
- **应用 / 取消**：应用写 `data\layout.ini`；取消回滚到上一次应用的模板（`layout.ini.prev`）。
- **卡片贴内容**：卡片尺寸自动等于最右 / 最下的模块边界，不再有隐形空白边。

### 外观

- **封面样式**：圆形（默认，可自转）或方形（不转）；方形也能拖着走。
- **封面调节**：大小、亮度、对比度、暖度、色相、暗角，全部在换封面那一次像素遍历里算完，不额外开销。
- **双色调**：给封面套一深一浅两个颜色（配好暖红 / 冷蓝 / 紫罗兰三套预设），嫌闷可调混合比例。
- **音乐律动条**（默认关闭）：真的频谱——环回采集 + 1024 点 FFT + 40Hz–16kHz 对数分箱；条数、粗细、长度、最大高度、上升/回落速度、颜色都可调。采不到音频时**归零（静音），不拿假数据糊弄**。
- **颜色**：每个颜色行末尾的「…」打开 48 色库，也能直接输入 `#RRGGBB`。

### 预设

- 内置两套（默认 1：左对齐紧凑；默认 2：居中留白），首次运行时自动写进配置。
- 「保存当前」把**整套外观 + 当前模板**一起存成一颗胶囊；点一下即套用，点 × 删除。
- 旧预设依旧可用（只含外观，不含模板）。

### 播放器

- 支持 9 家：Apple Music、Spotify、网易云、QQ 音乐、酷狗、酷我、AIMP、foobar2000、MD3Music 等（以 SMTC 上报为准）。
- 在「主页 → 监听的播放器」里勾选；一个都不勾，卡片就不出现。
- 浏览器标签页不算播放器，不会被误听。

### 修掉的问题

- **换曲时封面残留上一首 / 闪空盘**：改为原子替换，不再有中间的空圆盘。
- **暂停后进度条跳回 0**：暂停期间用自家时钟冻结位置，不再吃播放器那条滞后的上报。
- **曲末抽搐**：最后一秒判据锁存，不再在「到点归零」和「再报一次」之间抖。
- **预设要点两下**：现在是模板先落盘再刷外观，一次点击就生效。
- **切换封面样式后重启变回圆形**：`ArtShape` 现在会写回配置。
- **改任何外观设置卡片会往左滑一点**：删掉了残留的位移补偿。
- **切页会重播淡入**：同页刷新只换内容，不动画。

### 工程

- 删掉 `CardRender.cs`、`Smoke.cs` 等废弃渲染路径；绘制只剩一套「无状态渲染器」，画板与卡片共用。
- UI 文案全部进 `Strings.cs`（中英），英文界面不再残留中文。
- 封面自转从 60fps 动画时钟改 30fps 定时器步进，待机 CPU 从 26% 降到约 4%。

### 便携性

- 单文件 exe，解压即用：配置、日志、歌词缓存在 exe 同目录 `data\`；目录不可写时回退 `%APPDATA%\AppleMusicCard\`。
- 无安装、无管理员权限、无遥测；联网只用于取歌词与检查更新（可关）。
- Windows 10 1809+ / Windows 11，.NET Framework 4.6.2+（系统自带）。
